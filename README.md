## ✨ Features

### 🧠 3D Neural Brain
- **3,500+ particles** forming a brain-like structure
- **1,200+ neural connections** with dynamic lines
- **Glow rings** with independent rotation
- **Floating data nodes** with pulse animation
- **Scroll-driven** camera movement (dolly, orbit, depth)

### 🎯 Scroll-Driven Animations
- **Camera movement** synchronized with scroll position
- **Unified card reveals** across all sections (staggered entrance)
- **Auto-counting metrics** in the "Built for Scale" section
- **Smooth transitions** between sections

### 🎨 Premium Design System — Obsidian Precision
- **Deep-space black canvas** (`#070B0F`)
- **Refined dark surfaces** (`#0D1117`, `#11161B`)
- **Hairline borders** (`#1E252C`)
- **Mint accent** (`#4A9EFF`) — restrained, purposeful
- **Typography**: Space Grotesk (display) · Geist (body) · JetBrains Mono (code)

### 🖱️ Micro-Interactions
- **Custom cursor** with hover expansion
- **Premium card hover** effects (lift, glow, shadow)
- **Magnetic button** movement
- **Interactive metric counters**

### 📱 Fully Responsive
- **Desktop** — Full 3D cinematic experience
- **Tablet** — Optimized effects and layout
- **Mobile** — Dedicated experience with reduced 3D complexity
- **Reduced-motion support** for accessibility

### ⚡ Performance Optimized
- **Lazy loading** of 3D assets
- **Adaptive quality** (High / Medium / Low)
- **Device pixel ratio** capped at 2
- **Visibility-based rendering** (pause off-screen animations)
- **Efficient particle system** with instancing
