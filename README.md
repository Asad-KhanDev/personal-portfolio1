## ✨ Features

### 🧠 3D Neural Brain (Hero)
- **3,500+ particles** forming a brain-like structure
- **1,200+ neural connections** with dynamic lines
- **Glow rings** with independent rotation
- **Floating data nodes** with pulse animation
- **Scroll-driven camera** movement (dolly, orbit, depth)

### 🎯 Scroll-Driven Animations
- **Camera movement** synchronized with scroll position
- **Text reveal animations** (clip-path and opacity)
- **Staggered card reveals** across all sections
- **Smooth transitions** between sections
- **GSAP + ScrollTrigger** powered animations

| **Surface** | `#101418`, `#181c20`, `#1c2024`, `#262a2f`, `#31353a` |

- **3D hover tilt** on project cards
- **Magnetic button** movement
- **Hover telemetry** on skill cards
- **Custom cursor** (desktop)
- **Scroll progress** indicator with glow

### 📱 Fully Responsive
- **Desktop** — Full 3D cinematic experience
- **Tablet** — Optimized effects and layout
- **Mobile** — Dedicated experience with reduced complexity
- **Reduced-motion support** for accessibility
