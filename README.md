# ✨ Core Features

## 🧠 3D Neural Brain

The portfolio opens with an interactive neural visualization designed to create a strong cinematic first impression.

- 🧠 **3,500+ particles** forming a brain-like structure
- 🔗 **1,200+ neural connections**
- 💫 Dynamic glowing rings
- 🔵 Floating data nodes
- ⚡ Pulsing neural activity
- 🎥 Scroll-controlled camera movement
- 🌌 Depth and spatial movement

---

## 🎯 Scroll-Driven Experience

The entire website is designed around scroll interaction.

- 🎥 Camera movement synchronized with scrolling
- 🎬 Cinematic section transitions
- 🃏 Staggered card reveals
- 🔢 Animated metric counters
- 🌊 Smooth scrolling
- 🧭 Depth-based navigation experience
- ✨ Progressive visual storytelling

---

## 🎨 Obsidian Precision Design System

A carefully designed dark visual language built around contrast, spacing and restrained accents.

|---|---|
| 🖤 Canvas | `#070B0F` |

| 💻 Code Font | JetBrains Mono |

---

## 🖱️ Micro-Interactions

Small interactions are used throughout the experience to make the interface feel responsive and premium.

- 🖱️ Custom cursor
- ✨ Cursor hover expansion
- 🃏 Interactive card hover effects
- 🧲 Magnetic buttons
- 💡 Glow and shadow effects
- 🔢 Animated metric counters
- 🎯 Interactive CTAs

---

## 📱 Fully Responsive

The experience adapts across different screen sizes.

### 🖥️ Desktop
Full cinematic 3D experience with advanced visual effects.

### 💻 Tablet
Optimized layout and reduced rendering complexity.

### 📱 Mobile
Dedicated responsive experience with reduced 3D complexity.

### ♿ Accessibility
Includes reduced-motion support for users who prefer fewer animations.

---

# ⚡ Performance Engineering

The portfolio is designed to balance visual quality with browser performance.

- 🚀 Lazy loading of 3D assets
- ⚙️ Adaptive quality levels
- 📱 Device Pixel Ratio capped at `2`
- 👁️ Visibility-based rendering
- ⏸️ Off-screen animation pausing
- 🧠 Efficient particle rendering
- 📦 Instanced rendering techniques
- 📱 Mobile-specific optimization
