## 👨‍💻 About The Project

> **A premium cinematic portfolio experience combining 3D graphics, scroll-driven storytelling, interactive motion, and modern software engineering.**

This portfolio was designed to go beyond a traditional developer website.

Instead of simply presenting a collection of projects, it creates an **interactive visual journey** through my development experience, technical domains, projects, technologies, and creative work.

The experience combines:

- 🧠 Procedural 3D neural visualization
- 🎬 Cinematic scroll animations
- 🌀 Smooth scrolling
- ✨ Interactive micro-interactions
- 📊 Animated project metrics
- 💻 Technical project showcases
- 📱 Responsive layouts
- ⚡ Performance-aware rendering
- ♿ Reduced-motion accessibility

The result is a portfolio designed to demonstrate not only **what I build**, but also **how I think about technology, interaction, design, and engineering.**

# ✨ Core Features

## 🧠 3D Neural Brain

The hero section features a custom interactive neural-brain visualization designed using **Three.js and WebGL**.

### Visualization System

- 🔵 **3,500+ particles**
- 🔗 **1,200+ neural connections**
- 💫 Dynamic glowing lines
- 🌀 Independent glow-ring rotation
- 📡 Floating data nodes
- 💓 Pulsing node animations
- 🎥 Scroll-controlled camera movement
- 🔭 Dolly and orbit transitions
- 🌌 Depth-based visual layering

The neural system represents the intersection between:

**Computer Science × Artificial Intelligence × Creativity × Technology**

# 🎯 Scroll-Driven Experience

The portfolio is built around a cinematic scrolling experience rather than traditional page navigation.

Scrolling controls different parts of the visual system.

### Scroll interactions include:

- 🧩 Section transitions
- ✨ Card reveals
- 📊 Metric animations
- 🎬 Staggered entrances
- 🌀 Smooth scrolling

The goal is to make the entire website feel like a **continuous interactive story**.

### 💻 Tablet

- Touch-friendly interactions

---

# ⚡ Performance Engineering

A visually complex portfolio still needs to remain performant.

The project therefore uses several optimization strategies.

### Performance techniques

- ⚡ Lazy loading of 3D assets
- 🎚️ Adaptive rendering quality
- 🖥️ High / Medium / Low quality modes
- 📐 Device Pixel Ratio capped at `2`
- 👁️ Visibility-based rendering
- ⏸️ Pausing off-screen animations
- 🧠 Efficient particle systems
- 🔗 Optimized neural connections
- 📱 Mobile-specific rendering adjustments
- ♿ Reduced-motion support

The goal is to maintain the cinematic experience without unnecessarily consuming system resources.
